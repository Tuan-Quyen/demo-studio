# AI Video Trends (demo app)

Static, no-build demo page. All data in `data.js` is fictional sample data. No network access needed at runtime.

Run from this folder:

    python -m http.server 5173

Open http://localhost:5173

Key selectors: `hero-cta`, `chip-<slug>`, `card-v1..v8`, `modal`, `modal-close`, `section-*`. Sensitive fields carry `data-sensitive="true"`.
